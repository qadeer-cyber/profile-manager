# Chrome Stable and proxy location qualification

Visible Chromium profiles on Windows use an installed, Authenticode-verified Google Chrome Stable executable and the existing Azwah profile directory. Install or update Stable from Google. Headless automation and CI still use the separate pinned test runtime. A newer existing Chrome profile is blocked until Stable is at least as new. Preserve its original data for compatibility testing.

Automatic location is the default for Windows Chrome profiles with a proxy. Supply `AZWAH_MAXMIND_ACCOUNT_ID` and `AZWAH_MAXMIND_LICENSE_KEY` in the desktop application's environment. The service checks the exit using HTTPS through the assigned proxy and requests MaxMind GeoIP City data for that IP. The returned IP, approximate coordinates, provider accuracy radius, and IANA timezone must validate. The launcher checks the exit on every launch and reuses a matching location for up to 24 hours. Restart the profile after editing a proxy or location. Live IP changes during an open session are not applied.

Manual mode uses saved coordinates and accuracy with the regional timezone field. System mode leaves location and timezone to Chrome. The private browser control pipe applies overrides per browser context. Chrome continues to handle site permission choices. Existing Chrome-installed extensions need installed qualification. Azwah unpacked extension assignments are blocked because current Chrome Stable no longer accepts the prior launch mechanism.

Before release, install the candidate in an isolated Windows environment. Use two controlled public proxy exits with independently verified locations. Record Chrome executable path, verified publisher, process PID, browser-observed HTTP and HTTPS egress, DNS behavior where applicable, IANA timezone, geolocation and provider accuracy. Exercise permissions, fresh tabs, navigation, restart, reassignment, proxy outage and IPv6 where available. Confirm data and extension compatibility with legacy Owner migration, Admin and generated Office. Save screenshots and observations. Source prequalification does not replace these tests.
