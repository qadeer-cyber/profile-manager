# Local automation API

- Base: `http://127.0.0.1:<port>/api/v1`
- Auth: `Authorization: Bearer <token>` (`PM_API_TOKEN` / desktop `data/api-token`)
- Manual browsing: **default native** — does not enable automation silently
- Examples: `examples/local-automation/`

**MISSING:** bundled CLI binary, Selenium WebDriver server.
