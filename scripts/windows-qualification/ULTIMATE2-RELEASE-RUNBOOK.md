## Pre-release packaging contract

### RC tag (unique, never overwrite)

Pattern: **`ultimate2-unified-rc.<N>`** (monotonic `N`, e.g. `ultimate2-unified-rc.1`, `.2`, …)  
Tag must point at the **exact commit** that produced the EXE (same SHA in `BUILD-MANIFEST.txt`).

Alternative (semver): **`v0.5.0-ultimate2-rc.<N>`** — pick one scheme per release line; never reuse a tag.

### EXE artifact name (local build output)

`Profile-Manager-Ultimate2-unified-<SHA8>-offline-Setup-x64.exe`  
Example: `Profile-Manager-Ultimate2-unified-f15a6c1-offline-Setup-x64.exe`

GitHub Release asset: same filename or `{tag}-offline-Setup-x64.exe` — **must match SHA256SUMS.txt line**.

### SHA256SUMS.txt

GNU format, lowercase hex, two spaces before filename:

```
<64-char-sha256>  Profile-Manager-Ultimate2-unified-<SHA8>-offline-Setup-x64.exe
```

Generated by `Build-Ultimate2-Offline.ps1` and `Prepare-Ultimate2-ReleaseAssets.ps1`.

### BUILD-MANIFEST.txt

Fields: repository, branch, full commit SHA, source setup name, artifact name, SHA256, byte size, M8 summary (2/0/0), regression note, unsigned disclaimer, UTC timestamp.

### Pre-release notes (draft)

Template: `PRE-RELEASE-NOTES.template.md`.  
Prepared draft: `{EvidenceRoot}/PRE-RELEASE-NOTES-DRAFT.md`.  
State **unsigned** if no code-signing cert. Link Support ticket resolution and run URL for Windows qualification.

### Publish command (owner only — not automated in CI)

```powershell
# After Prepare-Ultimate2-ReleaseAssets.ps1 and manual review:
$tag = 'ultimate2-unified-rc.1'   # NEW tag only
$evidence = "$env:TEMP\pm-ultimate2-unified-build"
gh release create $tag `
  --repo qadeer-cyber/profile-manager `
  --target (git rev-parse HEAD) `
  --title "Ultimate 2.0 unified RC (Windows offline x64)" `
  --notes-file (Join-Path $evidence 'PRE-RELEASE-NOTES-DRAFT.md') `
  --prerelease `
  (Join-Path $evidence 'Profile-Manager-Ultimate2-unified-*-offline-Setup-x64.exe') `
  (Join-Path $evidence 'SHA256SUMS.txt') `
  (Join-Path $evidence 'BUILD-MANIFEST.txt')
# Do NOT pass --latest for RC builds unless Lead explicitly approves.
```
